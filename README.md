# 🤖 NovaAI — AI Chatbot

NovaAI is a modern AI chatbot built using **Python, Flask, HTML, CSS, JavaScript, and the OpenAI API**.

The project provides a simple, responsive interface for interacting with an AI assistant while supporting conversation history and multiple chats.

## ✨ Features

- 🤖 OpenAI-powered AI assistant
- 💬 Interactive chat interface
- 🧠 Conversation history
- ➕ Create new conversations
- 🗑️ Clear conversations
- 🌙 Dark/light mode
- 📱 Responsive mobile-friendly design
- 🔄 Conversation context
- ⚡ Flask REST API backend
- 🔐 Secure API key configuration using `.env`

## 🛠️ Technologies

### Frontend

- HTML5
- CSS3
- JavaScript

### Backend

- Python
- Flask
- Requests
- python-dotenv

### AI

- OpenAI API
- OpenAI Responses API
